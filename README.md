# Green House Recepções

Site demonstrativo da Green House, em São Luís. Layout responsivo, galeria ampliável e formulário que prepara uma mensagem para o WhatsApp oficial.

## Publicar na Vercel

Importe este repositório em https://vercel.com/new e clique em Deploy. A configuração está em `vercel.json`:

- Framework: Other
- Build command: `npm run build`
- Output directory: `dist`
- Root directory: raiz do repositório

Não são necessárias variáveis de ambiente ou dependências externas.

## Arquivos

- `dist/index.html`: conteúdo
- `dist/style.css`: estilos e responsividade
- `dist/script.js`: galeria, seleção de evento e WhatsApp
- `dist/assets/`: imagens locais

As imagens e os registros pertencem aos respectivos autores creditados no rodapé. Dados comerciais e direitos de uso devem ser validados com a empresa antes de uma publicação comercial definitiva.
